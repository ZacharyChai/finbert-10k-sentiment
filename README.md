# Does 10-K risk-factor tone predict stock returns? — FinBERT vs. a dictionary

A financial-NLP study: for a fixed panel of large-cap US firms (2014–2023
fiscal years), pull every annual report from SEC EDGAR, extract the **Risk
Factors** section (Item 1A), score its tone two ways — **FinBERT** (a
finance-domain BERT) and the **Loughran–McDonald** finance sentiment dictionary
(a transparent word-count baseline) — and test whether that tone, and especially
the *year-over-year change* in tone, predicts forward stock returns and forward
realised volatility. The design point: FinBERT is only worth the dependency if
it carries signal the dictionary misses.

**Headline:** Across 376 filing-years (41 firms, FY2014–2023), 10-K risk-factor
tone **does not predict forward abnormal returns** — 0 of 25 predictive
regressions are significant, and FinBERT adds nothing over the Loughran–McDonald
word list. Tone *does* line up with forward **volatility** (most-negative tercile
0.31 vs least-negative 0.24, t ≈ 3.5), but that is mostly the persistence of
volatility: controlling for the stock's trailing vol, the relationship is
marginal (p ≈ 0.08) or gone (FinBERT, p ≈ 0.54). Full write-up in
**[MEMO.md](MEMO.md)**.

## Findings at a glance

| Question | Result |
|---|---|
| Do the two tone measures agree? | Moderately — FinBERT %-negative vs LM negative-word fraction r = **0.57** |
| Does tone reflect the firm's recent performance? | Yes (construct validity holds): trailing volatility → more negative tone, t ≈ **−4.4 / +4.2 / +4.0**, p < 0.001; trailing return → more negative tone, weaker (t ≈ −2.2 / +1.9) |
| Does tone predict forward **abnormal returns**? | **No** — 0 / 25 regressions significant at 5% (≈1.2 expected by chance); tercile sort spreads all \|t\| < 1.9 |
| Does tone predict forward **volatility**? | Raw: yes — LM-negativity tercile sort H−L = **+0.074, t = 3.5**, monotonic 0.24 → 0.27 → 0.31. Controlled for trailing vol: LM p ≈ 0.08, FinBERT p ≈ 0.54 |
| Does FinBERT beat the dictionary? | **No** — in a combined model neither has significant incremental power over the other, for any outcome |
| Placebo: does tone "predict" the **past** (trailing 6m return)? | No (all p > 0.24) — the return null isn't a misplaced-power artefact |
| Multiple-testing ledger | 25 tests, **0** significant at p < 0.05, 0 after Bonferroni |

## Method

- **Filings.** 10-K primary documents from EDGAR (`data.sec.gov` submissions API
  + `www.sec.gov/Archives`). Item 1A is delimited by locating the real section
  *heading* ("Item 1A. Risk Factors" followed by body text, not a cross-
  reference) and slicing to the next item heading. Sections under 1,500 chars
  (cross-reference stubs) fall back to Item 7 (MD&A) or are dropped.
- **Tone.**
  - *FinBERT* (`ProsusAI/finbert`): each sentence classified positive / negative
    / neutral; the filing's `net_sentiment` = mean(P(pos) − P(neg)) over an
    even-strided sample of ≤120 sentences; `pct_negative` = share of sentences
    whose top label is negative.
  - *Loughran–McDonald* (via `pysentiment2`): negative- and positive-word counts
    on the same sampled sentences; `neg_frac` = negatives / tokens.
  - Both are z-scored across the full sample so regression coefficients read as
    "per 1 SD of tone".
- **Outcomes.** From daily adjusted-close prices (Yahoo Finance), keyed to the
  actual filing date, skipping the first trading day:
  - forward simple return and **abnormal return** (stock − SPY) over +1 / +3 /
    +6 months
  - forward realised volatility (annualised, 63 trading days) and its change vs.
    the trailing 63-day realised vol
- **Controls.** Trailing 63-day realised vol, trailing 126-day return, log
  trailing-year median dollar volume (size/liquidity proxy), log section length.
- **Regressions.** `outcome ~ z(tone) + controls | firm FE + fiscal-year FE`,
  standard errors two-way clustered on firm and year (`statsmodels` OLS with a
  clustered covariance). Also a within-year **tercile portfolio sort** (the
  finance-standard high-minus-low presentation) and a **placebo** that regresses
  the *trailing* return on tone.

## Data

- **10-K filings:** SEC EDGAR: 41 firms, 376 filings. The 45-firm universe loses
  4 firms (IBM, MCD, WFC, GE) whose Item 1A markup the heading slicer can't
  delimit, and ~10 firms lose one or more individual years the same way. Raw
  HTML is fetched and cached under `data/raw/filings/` (git-ignored, large,
  re-fetchable); the extracted-and-scored result per filing is cached as JSON
  under `data/processed/sentiment_cache/` **and committed**, so `analysis.py`
  and even `build_dataset.py` reproduce without EDGAR access or the FinBERT
  model.
- **Prices:** Yahoo Finance daily adjusted close, 2013–2025, cached in
  `data/processed/prices.csv`.
- **SEC requires a descriptive User-Agent** with contact info on every request;
  set your own via the `SEC_USER_AGENT` environment variable.

## Reproduce

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt        # torch 2.2.2 + transformers 4.36 (see notes)
make all                               # build_dataset.py (from cache) then analysis.py + tests
```

- `make analysis` — regressions, sorts, figures, `output/*.csv` (uses the
  committed sentiment cache; seconds).
- `make data` — rebuild `filings.csv` from the cache; add `--refetch`
  (`python run_all.py --refetch`) to re-pull 10-Ks and re-run FinBERT from
  scratch (~1.5 h on CPU, downloads a ~440 MB model).
- `make test` — fast unit tests. `make test-slow` also runs the FinBERT check.

**Dependency notes.** `torch==2.2.2` is the last release with x86-64 macOS
wheels; it needs `numpy<2`; and `transformers` is pinned to 4.36 because newer
versions refuse to load `.bin` checkpoints on `torch<2.6` and `ProsusAI/finbert`
ships no safetensors.

## Caveats

<!-- expanded in MEMO.md -->
- 376 filing-year observations is small for cross-sectional return prediction;
  overlapping forward-return windows induce correlation the clustered SEs only
  partly absorb.
- FinBERT is trained on analyst-note / news phrasing, not the legalese of a risk
  section; sentence-level "neutral" dominates and the signal is in the tails.
- The Loughran–McDonald list here is the `pysentiment2` build (~2018 vintage,
  stemmed), not the latest master dictionary.
- Sentiment is scored on a 120-sentence sample per filing, not the whole section.
- Survivorship: the universe is firms that were large-cap and filing 10-Ks for
  the whole window.

*Résumé line:* Built a financial-NLP pipeline that scores 10-K risk-factor tone
with FinBERT and the Loughran–McDonald dictionary across 376 filings, and tested
it against forward abnormal returns and realised volatility with firm/year fixed
effects, a within-year portfolio sort, and a past-return placebo — finding a
clean null on returns and showing the transformer adds nothing over the word
list for this task.
